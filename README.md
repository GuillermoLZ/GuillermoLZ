### 👨‍💻 Sobre mí

Soy Desarrollador **Frontend / Fullstack** con más de **4 años de experiencia** construyendo aplicaciones web empresariales, escalables y orientadas a una excelente experiencia de usuario.

- 🚀 **Especializado en Frontend:** Arquitectura modular en **Vue.js 3** y TypeScript, diseño de interfaces reactivas con Pinia/Vuex y frameworks como Ant Design Vue, Vuetify y Quasar.
- ⚙️ **Solidez en Backend:** Desarrollo de APIs REST robustas con **Django / Django REST Framework**, Laravel y Lumen, aplicando control estricto de concurrencia, transacciones atómicas y seguridad JWT.
- 📡 **Tiempo Real e Integraciones:** Experiencia integrando comunicación en tiempo real con **WebSockets, WebRTC y Asterisk**, pasarelas de pago (**Niubiz**), CRMs (**HubSpot API**) y modelos de síntesis de voz con IA (**F5-TTS**).
